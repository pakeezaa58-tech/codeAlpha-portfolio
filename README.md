# codeAlpha-portfolio
https://pakeezaarshad-portfolio-lyart.vercel.app/
## Sections

- **Home:** introduction and quick links
- **About:** who I am and what I build
- **Skills:** Frontend (HTML, CSS, JavaScript, React), Programming (Python), Tools (Git and GitHub)
- **Projects:** Image Gallery, Calculator and this Portfolio, linked to my GitHub repositories
- **Resume:** designed resume with a one-click PDF download
- **Contact:** contact form, phone, email and social links

## Features

- Clean, responsive layout for phones, tablets and desktops
- Smooth scrolling, scroll animations and hover effects
- Resume download button (`Pakeeza_Arshad_Resume.pdf`)
- Projects are linked to GitHub automatically: any new repository named `CodeAlpha_...` appears in the Projects section by itself, and projects not uploaded yet show "Uploading soon"
- Mobile menu

## Technologies

HTML5, CSS3, JavaScript (ES6), GitHub API

## Project structure

```
CodeAlpha_Portfolio/
├── index.html
├── style.css
├── script.js
├── Pakeeza_Arshad_Resume.pdf
└── README.md
```

## How to run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. To put it online: GitHub repository, Settings, Pages, branch `main`, folder `/ (root)`, Save.
